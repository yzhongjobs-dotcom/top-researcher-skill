## 0. 两篇的简要画像

### A：Constrained Variable Impedance Control using Quadratic Programming（ICRA 2022）

- **基本信息**：Jin, Qin, Liu, Zhang, Yu（浙江工业大学），ICRA 2022，Philadelphia，pp.8319–8324，6 页，DOI 10.1109/ICRA46639.2022.9812210 [原文 A p.1 页脚]。检索时的引用数为 11（`index.json`，检索日期未记录）。类型为理论/方法型。PDF：`D:\桌面\科研Agent Harness设计\impedance-control-e2e\source-materials\user-batch-v2\Constrained_Variable_Impedance_Control_using_Quadratic_Programming.pdf`。全文已读。
- **逻辑链**：变阻抗控制（VIC）需要在跟踪精度和接触柔顺之间权衡 [A p.2 Sec.III]；已有的 MPC/LQR 类 VIC 没有考虑位置、速度约束，也没有考虑阻抗参数的取值范围 [A p.1]。作者提出"新阻抗模型"：把 u=(−k/m, −d/m, 1/m) 直接作为控制输入，这样阻抗约束就变成输入约束，单步问题成为 QP（Eq.(7)–(13)）。另外引入一个补偿力 f_c，用 H 步预测的第二个 QP 来保证位置和速度约束（Eq.(14)–(24)）。最后在 Franka 上做矩形和螺旋轨迹实验 [A p.4–6]。
- **方法**：两个串联的 QP（Algorithm 1）。没有稳定性或无源性分析。
- **实验**：真机实验，高层 50 Hz、底层 1 kHz；k∈[1000,1500] N/m [A p.4]。内容包括：只加阻抗约束、人手碰撞、加位置约束（x_max=0.4 m，H=5）、外力推越界时有无 f_c 的对比，以及螺旋轨迹 [A p.4–6]。**没有与任何其他方法比较，也没有数值指标**，结论全部来自时序图。
- **贡献**：三条：阻抗约束及其 QP 化、补偿力 QP、两个 QP 的组合 [A p.1–2]。

### B：Model Predictive Variable Impedance Control of Manipulators for Adaptive Precision-Compliance Tradeoff（TMECH 2023）

- **基本信息**：作者与 A 相同，IEEE/ASME TMECH vol.28 no.2，pp.1174–1186，13 页，DOI 10.1109/TMECH.2022.3204350。2022-04-05 收稿，07-18 修回，09-01 接收 [原文 B p.1]。检索时的引用数为 84。类型为理论/方法型。PDF：`D:\桌面\科研Agent Harness设计\impedance-control-e2e\source-materials\user-batch-v2\Model_Predictive_Variable_Impedance_Control_of_Manipulators_for_Adaptive_Precision-Compliance_Tradeoff.pdf`。全文已读。
- **逻辑链**：阻抗控制本身就是精度与柔顺之间的一种固定权衡，复杂任务需要在线调整这一权衡 [B p.1, p.3]。示教类 VIC 拿不到真实的阻抗参数，RL 类 VIC 依赖试错并受仿真到实物差距影响，经典 MPC-VIC 的代价函数不能准确表达这一权衡，也加不了约束 [B p.1–3]。作者沿用新阻抗模型（Eq.(13)–(14)），设计单步 MPC（OS，QP）和多步 MPC（MS，非凸，iLQR），再用 energy tank 修正变刚度以保证无源性（Sec.V, Theorem 1）。实验在真机上比较固定高/低阻抗、经典 MPC-VIC 和 RL-VIC [B p.7–11]。
- **贡献**：四条：新模型、阻抗约束、OS/MS 两种 MPC、基于 tank 的无源性 [B p.2]。

## 3. 各阶段的差异

### 3.1 研究现状

| | A | B |
|---|---|---|
| 组织 | 固定阻抗 → 启发式 VIC → RL → 基于模型的最优 VIC（MPC/LQR）→ 缺少约束 [A p.1] | 固定权衡模式 → 示教类 VIC（拿不到真实阻抗）→ RL（试错、仿真到实物差距）→ MPC/LQR 类 VIC（加不了约束，代价函数不准）[B p.1–2] |
| 差距怎样确立 | 用一句"之前没人考虑这些约束"带过 [A p.1] | **把最强对手的公式写出来**：经典 MPC-VIC 的模型 Eq.(9)、代价 Eq.(10)、Riccati 解的形式 Eq.(12)，并指出两个机制性缺陷：①代价权衡的是误差与 ω，而 ω 不等于柔顺度；②一加约束，Eq.(12) 的形式就不再成立，阻抗参数也就无法从解中恢复出来 [B p.3] |
| 无源性 | 只在参考文献中出现 Ferraguti 的 tank 工作 [A ref.5] | 单列为一个问题，引用 [25]–[27] [B p.4] |

[推断] 这是升级中最值得学的一步：**从"别人没做 X"变成"别人的表述为什么做不了 X"**。B 的差距是用对手自己的方程推出来的，审稿人可以逐式核查。

### 3.2 研究问题

- A 的问题清单是两条：设计带阻抗约束的最优 VIC；保证位置和速度约束 [原文 A p.2]。这是**功能层面**的表述。
- B 的题名、摘要和引言首段都以"自适应的精度—柔顺权衡"为中心；Sec.III 列出四个问题：新模型、约束、MPC 设计、无源性 [原文 B p.1, p.4]。约束的作用也变了：在 A 里是需要满足的限制，在 B 里还是**注入任务知识的手段**。例如 Eq.(50) 让刚度下限随离目标点的距离变化，靠近目标时提高精度 [原文 B p.10]。
- [推断] 问题从"受约束的 VIC 怎样求解"提升到"怎样按任务状态在线调整精度—柔顺模式"。这是**同一矛盾的能力化重述**，不是发现了新矛盾；能力化之所以站得住，是因为 B 补上了对应的证据，即两端指标和试管插入任务。

### 3.3 方法

| 维度 | A | B | 判断 |
|---|---|---|---|
| 输入表示 | 新阻抗模型 | 同上 | 原样继承 |
| 单步求解 | QP（Eq.(11)–(13)） | 单步 MPC，即同一个 QP，并证明严格凸（Eq.(23)–(25)） | 换了名字，把它放进 MPC 框架统一叙述 |
| 阻抗约束 | 只有过阻尼一种 | 过阻尼 + 自由阻尼两种；约束和权重都可以依赖状态 [B p.5] | 扩展了通用性 |
| 状态约束 | 补偿力 f_c，H 步预测 QP，**硬约束** [A Eq.(17)(18)] | 多步 MPC **直接优化阻抗序列**：tanh 重参数化、barrier 函数软化、用 iLQR 求解 [B Eq.(26)–(35)] | 控制结构改变。注意：A 已经有多步预测，"QP→MPC"并不是第一次引入预测；B 换成软约束，实验中轻微越界 [原文 B p.10]，相对 A 的硬约束是**一种退让**，不是单调的升级（Codex 提出，已核） |
| 无源性 | 无 | 用 energy tank 修正变刚度部分；连续时间下的 Theorem 1；离散实现假设"周期足够小"[B p.6–7] | 新增了理论闭环；保证对象限定在理想阻抗子系统 |
| 执行顺序 | 两个 QP → 加速度 → 力矩 | MPC → tank 修正 → 加速度 → 力矩 → 更新 tank 能量（Algorithm 1）[B p.8] | tank 是在 MPC **之后**修正的，修正后 MPC 预测的状态约束是否还成立，正文没有给出联合保证（Codex 提出，[推断]） |

[推断] B **放弃了 A 的补偿力**，可能的理由是：在阻抗结构之外另加一个力，会让"阻抗"这层解释和基于 tank 的无源性分析都变得复杂；全部改用阻抗参数来实现约束（靠近边界时把刚度降到下限、阻尼升到上限，Fig.7(d)(e)），整个系统就仍然是一个变阻抗系统，可以统一分析。这是期刊版**为了理论一致性而改结构**的例子。

### 3.4 实验

|---|---|---|
| 平台与频率 | Franka；50 Hz / 1 kHz | Franka；T=15 ms（约 67 Hz）；z 方向用 Jung [28] 的力控 [B p.8] |
| 对照 | 只有自身有无约束的对比 | **固定两端**：大阻抗 k=1500、小阻抗 k=100，正好是刚度约束的上下界；**两个竞争 VIC 族**：经典 MPC-VIC [20][21] 和 RL-VIC [16] [B p.8] |
| 指标 | 只有时序图 | 两端都测：最大/RMS 位置误差，最大/RMS 接触力（Fig.4） |
| 机制与参数 | 有无 f_c | tank 参数 k_c 的敏感性（Fig.5，k_c=1400 时 tank 耗尽，切换处出现力的颤动）；状态相关 k_min 与常数 k_min 的对比（Fig.9(e)，常数时试管插入产生大的碰撞力） |
| 场景 | 矩形、螺旋、人手碰撞、外力推越界 | 波浪形障碍内接触跟踪；位置约束（多个边界值）；无接触的试管抓取—插入，比较快、慢参考轨迹 |

|---|---|---|---|---|
| 本文 VIC | 0.023 | 0.016 | **9.7** | **4.4** |
| 经典 MPC-VIC | **0.021** | 0.016 | 14 | 6.2 |

- 本文方法的位置误差**不是最好**（最大误差比经典 MPC-VIC 大 0.002 m），优势全部在接触力一侧：最大力比经典 MPC-VIC 低约 31%（9.7 对 14），RMS 力低约 29%（4.4 对 6.2），已经接近完全柔顺的 SI（3.7）。

### 3.5 贡献定位

- **A**：贡献落在机制和求解结构层面，即受约束 VIC 的可执行求解方法。
- **B**：贡献落在能力层面，即任务相关的精度—柔顺在线调整。四条贡献分别由模型、约束、OS/MS 和 tank 承担。
- [推断] B 的四条贡献是相对**经典 MPC-VIC**写的，而新模型、阻抗约束和单步 QP 在 A 中已经出现；所以相对 A 的真正增量只有 MS-MPC、tank 无源性、自由阻尼与状态相关约束，以及证据（Codex 提出，已核）。

## 4. 差异说明了什么：会议版到期刊版补了什么

1. **把差距从"没做"改成"为什么做不了"**：写出最强对手的方程，指出机制缺陷（B p.3）。这一步不增加任何算法，却是论证力度提升最大的地方。
2. **把功能改写成能力**：同一个模型，从"能施加约束的技巧"重新表述为"让代价函数能准确表达权衡的表示"[B p.2 贡献 1]，并让题名改为表达能力。
3. **补上该问题最看重的性质**：变阻抗系统最受关注的是无源性，B 用 tank 和 Theorem 1 补上了。
4. **补全证据**：两端固定参数对照 + 两个竞争方法族 + 同时测量两端的指标 + 一个参数敏感性分析 + 一个设计对比（状态相关 k_min）+ 一个不同类型的任务（无接触插入）。
5. **主动交代代价**：MS-MPC 非凸、软约束会轻微越界、tank 切换会引起颤动、没有考虑模型不确定性 [B p.4, p.9–11]。
6. **没有补的**：计算时间、重复次数与统计、与 A 的直接比较、对时变约束的理论覆盖。[推断] 这些是 TMECH 能接受、但在 T-RO/IJRR 上很可能被追问的缺口。对照同组之后的工作：TMECH2025 就补上了"先调到相近精度再比较"的公平协议。

[推断] 这组样本不能证明以上补充是录用的必要或充分条件（没有审稿记录），也不能推出"TMECH 比 ICRA 更重理论"：同组的 RA-L2022 同样是短文，却以 Lyapunov 稳定性为核心（Codex 提出，已核）。

**对旧分析的更正**：
- `prior_standards/2026-09-07` §5.1 说 A 有"experimental comparisons"。原文中 A 只做了有无约束的自身对比，没有与其他方法比较 [A p.4–6]。
- `examples/first_round` §7 说 B 只与固定高、低阻抗比较。原文中 B 还比较了经典 MPC-VIC 和 RL-VIC [B p.8–9]。

## 5. 关键决策点（升级时的选择）

**D1 主问题怎样表述**
- 可能的选项：继续以约束求解为中心 / 以能力（自适应权衡）为中心
- 实际选择：以能力为中心 [B p.1–4]
- 放弃了什么：用"约束清单"组织全文
- 理由：[推断] 能力表述能把参数变化、约束和任务阶段统一起来
- 对后文的影响：必须同时测量两端，并补一个突出精度一端的任务（试管插入）

**D2 状态约束通过什么实现**
- 可能的选项：保留补偿力 / 直接优化阻抗序列
- 实际选择：直接优化阻抗序列（MS-MPC）[B p.5–6]
- 放弃了什么：硬约束和凸性
- 理由：[推断] 整个系统保持为一个变阻抗系统，可以统一做无源性分析
- 对后文的影响：需要 iLQR 求解；实验中轻微越界，作者承认了这一点 [B p.10]

**D3 求解器怎样配置**
- 可能的选项：只用一种求解器 / 区分 OS 与 MS
- 实际选择：区分 OS（QP、全局最优、只处理阻抗约束）和 MS（非凸、可处理状态约束）[B p.4]
- 放弃了什么：一套方法覆盖所有情况的叙述
- 理由：[原文 B p.4] 两者各有长处
- 对后文的影响：实验按两类求解器分别安排；TMECH2025 后来批评 MS 只能得到局部最优

**D4 无源性怎样处理**
- 可能的选项：不处理 / 在 MPC 内加约束 / 在 MPC 之后用 tank 修正
- 实际选择：事后用 tank 修正 [B p.6–8]
- 放弃了什么：规划与修正的联合保证
- 理由：[推断] tank 是成熟方案（Ferraguti [25]），可以直接套用
- 对后文的影响：k_c 选择不当时会颤动（Fig.5）；保证对象限于连续时间的理想阻抗子系统

**D5 怎样选对照**
- 可能的选项：只用固定阻抗 / 再加竞争方法族
- 实际选择：固定阻抗的上下界（100/1500，与约束一致）+ 经典 MPC-VIC + RL-VIC [B p.8]
- 放弃了什么：A 的自身对比
- 理由：[推断] 两难问题要求对照站在两端
