## 2. 全文逻辑链

**应用需求**：超声扫描既要控制接触力（力过大会造成图像伪影、疼痛和组织损伤），又要保持良好的声耦合；探头还要贴着形状复杂的体表移动，并对准法向 [原文 p.1]。**核心矛盾**：现有 RUS 系统用"笛卡尔阻抗 + 前馈力"来产生接触力，但前馈力在失去接触时行为不可预测、不无源；解析曲面方法又处理不了任意曲面 [原文 p.1–2]。**核心洞见**：如果把任务坐标定义成"到曲面的有符号距离 + 工具轴与曲面法向的对齐误差"，曲面问题就变成了经典阻抗控制问题。把期望距离设成负值（设到曲面里面），接触力就由被动的弹簧产生，不再需要力控制；这个设定值同时直接限定了最大压入深度 [原文 p.1–3]。**方法**：
1. 用平行曲面构成的叶状结构（foliation）定义坐标 p=(d, ε)（Eq.(3)–(7)）；
2. 用微分几何中的 Weingarten 映射和第二基本形式推导雅可比，并对平行曲面做曲率修正（Eq.(9)–(14)）；
3. 可选地加入 ARAP 参数化坐标 s，用来指定在曲面上的位置（Eq.(15)–(20)）；
4. 在三角网格上，用 AABB 树做最近点查询，用重心插值估计法向和曲率，从而实时实现 [p.5–6]。

**证据**：在 DLR MIRO 七自由度机器人和硅胶模体上跟踪 Lissajous 轨迹（参数化坐标 RMSE 约 1 mm）；与"笛卡尔阻抗 + 前馈力"和"网格阻抗 + 前馈力"比较，三者接触力的均值和标准差相近，但前两者各出现一次失去接触后的冲击 [原文 p.7–8]。**主张**：一种只靠经典无源阻抗控制、就能在任意曲面上连续调节接触力并限定压入深度的 RUS 控制方式 [原文 p.2 C1–C3, p.8]。

## 3. 研究现状

**组织方式**：从三个来源说明"前馈力 + 预计算轨迹"的局限，而不是按技术谱系逐代写 [原文 p.1–2]。

1. **力控制范式**：间接力控制（前馈力）在失去接触时不无源；直接力控制或混合位置/力控制缺乏鲁棒性。最接近的是 Schindlbeck & Haddadin [7]，它在任意**解析**曲面上结合力跟踪与阻抗控制，并借助 energy tank 证明了无源性 [p.1]。
2. **RUS 系统**：
   - Virga [8] 只在 x、y 方向用笛卡尔阻抗，作者认为它不适合复杂几何；
   - Zettinig [10] 用阻抗加前馈力；
   - Jiang [9] 用力/力矩传感器调整探头姿态；
   - Huang [12] 用深度相机点云做点到点控制 [p.1–2]。
3. **制造类任务**（打磨、绘画）：通常预计算笛卡尔轨迹，再用阻抗加前馈力执行，因此不能做手把手引导（hands-on）；Kana 等 [16] 用一个沿曲面"游走"的虚拟代理点实现了 hands-on，但施加接触力仍靠主动力控制 [p.2]。

**最接近的工作与正面比较**：
- 与 [7]：作者指出自己不需要额外的力控制，并能处理离散网格，而不只是解析曲面 [原文 p.3, p.8]；
- 与 [16]：作者专门写了一段机理区别 [原文 p.5]。[16] 的代理点有一阶动力学，任务力因此依赖历史，无法积分成势场；本文直接取最近点，坐标只依赖 q。这正是本文能继承经典无源性的关键。

**差距怎样确立**：三类工作在"失去接触时的无源性""任意曲面""一个控制器同时支持手把手、遥操作和自主扫描"这三点上无一同时满足 [原文 p.2 "In contrast to [7]–[10], [13]–[16]"]。[推断] 差距是按几个具体能力逐项列出的，不是"都忽略了某因素"这种笼统说法。不过正文没有给出对比表，也没有在实验中复现 [7] 或 [16]。

## 4. 研究问题

- **问题层级**：系统能力层面，即在任意曲面上以被动方式产生接触力，并贴合法向扫描；落到一个控制表述问题上：任务坐标应该怎样定义。
- **核心矛盾**：RUS 需要稳定的接触力，但产生接触力的常用手段（前馈力或力控制）会在失去接触时破坏无源性 [原文 p.1, p.8]；曲面几何复杂，又让预计算轨迹的做法难以支持手把手引导 [原文 p.2]。
- **重要性从哪里来**：
  - 临床需求：力过大会造成伪影、疼痛和损伤 [p.1]；
  - 安全：失去接触后会产生冲击 [p.7–8]；
  - 可用性：同一套控制器要覆盖三种操作模式 [p.2]。
- **解决后改变什么**：接触力和最大压入深度都由一个几何设定值 d_d 直观地决定，失去接触时行为确定、安全 [原文 p.8]。

## 5. 方法

**实际增量**：
- **继承**：经典阻抗控制律 Eq.(4)/(20)、双对角化阻尼设计 [19]、零空间投影 [32]，以及计算机图形学的现成工具（AABB 树 [26]、二次曲面拟合曲率 [27]、ARAP 参数化 [29]、libigl [31]）[原文 p.3–6]。
- **新增**：曲面任务坐标 p=(d, ε) 与 ρ=(s, d, ε)，以及与之对应的雅可比。雅可比中的 Jεv 由 Weingarten 映射给出（Eq.(13)）；平行曲面上的曲率修正为 Eq.(14)；平行曲面上的参数化梯度修正为 Eq.(18)。

**每个部件对应哪个困难：**

| 部件 | 困难 | 出处 |
|---|---|---|
| 有符号距离 d 加负设定值 | 不用力控制产生接触力，并限定压入深度 | Eq.(6), p.3 |
| 平行曲面叶状结构，并限制 \|d\|<r_min | 让离开曲面的点与曲面上的点一一对应（映射 Ψ_d），保证坐标连续 | Eq.(1)–(2), Fig.2, p.2–3 |
| 四元数向量部 ε | 工具轴对准曲面法向 | Eq.(7) |
| Jεv = Jεω[n]×PᵀIIP | 沿曲面切向运动时法向会变化，需要映射到姿态误差的变化率 | Eq.(12)–(13), p.4 |
| 修正后的第二基本形式 Ĩ I（Eq.(14)）和第一基本形式（Eq.(17)） | 在平行曲面（d≠0）上，曲率和速度比例都会变化 | p.4–5 |
| 最近点代理点（不用动态代理） | 坐标只依赖 q，任务力可以积分成势场 | p.5 |
| 三角网格加重心插值 | 处理任意拓扑和尖角；实际可以从 CAD、扫描或视觉获得网格 | p.5–6 |
| ARAP 参数化 | 遥操作时，参数域中的速度与曲面上的速度近似等距、保角 | p.6 |

**是否有更简单的替代**：
- 正文实验中的替代方案就是"笛卡尔阻抗 + 前馈力"（III-B1）和"同一套网格坐标 + 前馈力"（III-B2）[p.7–8]；
- 解析曲面方法 [7][24] 作为替代，在正文中被讨论过 [p.5]；
- 正文没有讨论"用点云或 SDF 直接查距离"之类的其他几何表示。

**理论与执行是否闭合**：
- 正文**没有给出新的稳定性或无源性定理**，而是说本方法"inherently guaranteeing stability and passivity" [原文 p.2]，依据是经典无源阻抗控制 [17] 与"坐标只依赖 q"这一设计 [p.5]。[推断] 这是一个刻意的设计选择：重新定义坐标之后，已有的无源性结论可以直接沿用，不必另写证明；
- "固有无源"严格来说只对**固定**的设定值和刚度成立。实验跟踪的是时变的 Lissajous 轨迹，III-A 中的 d_d 也随时间变化 [Eq.(23)]。平衡点移动或刚度改变都会改变储能，而正文没有给出这种情况下的能量预算（Codex 提出，[推断]，依据 Eq.(20) 与实验设置）；
- "限定最大压入深度"是有限刚度弹簧给出的平衡位置，不是硬约束；瞬态时可能超过，正文没有给出界（Codex 提出，[推断]）；
- 代价是适用范围：坐标只在 |d|<r_min 内有定义，实验中保守地取 d_max=15 mm [p.6]。另外，r_min 是**局部**曲率半径；若曲面有两片相距很近但不相邻的部分（如薄壁），最近点可能在全局意义下不唯一。局部曲率界不能排除这种情况（Codex 提出，[推断]）；
- 参数化坐标 s 要求曲面是盘状拓扑（无孔、单边界）[原文 p.6]，所以"任意曲面"对核心坐标 p 成立，对完整的 ρ 不完全成立（Codex 提出，已核）；
- 尖角处的处理靠"平滑法向图"[p.5]，没有理论分析；
- 执行层面：控制器嵌入 3 kHz 的实时回路 [p.6]，但给出的单次计算时间 t_call=11.91 ms 与 3 kHz（约 0.33 ms 周期）矛盾。原页确实写的是 ms [原文 p.6，已对照渲染图]。[推断] 可能是 µs 的笔误，也可能是几何量在较慢的回路中更新，正文都没有交代。

**为什么一看就像顶刊方法**：
- 先给出几何对象（有向曲面、法向场、平行曲面、叶状结构），再定义坐标，最后推导雅可比，顺序是"对象 → 坐标 → 雅可比 → 控制律"[p.2–5]；
- 先在光滑设定下推导，再单独一节讲离散化 [p.5–6]，读者能分清哪些是数学、哪些是实现；
- 每个几何概念都配图：Fig.1 坐标、Fig.2 叶状结构、Fig.3 曲率、Fig.4 参数化、Fig.5 离散化；
- 实现细节写到可复现：网格规模、最大曲率、d_max、建树时间、所用库、零空间处理方式 [p.6]；
- 局限放进未来工作，并写得具体：临床设置、视觉伺服外环、刚度估计、绕探头轴的旋转、虚拟夹具、焦点问题 [p.8–9]。

## 6. 实验验证

| 主张 | 证据 | 出处 |
|---|---|---|
| C2 坐标可以跟踪任意曲面上的复杂轨迹，并对准法向 | III-A：Lissajous 轨迹（幅值 45 mm，ω₀=0.12 s⁻¹）。RMSE_s1=0.917 mm，RMSE_s2=1.465 mm；d_d>0 段 RMSE_d=0.871 mm；Fig.7(c) 的 Gauß 映射显示工具轴贴合法向 | Eq.(23), Fig.7, p.7 |
| 叶状结构使各坐标相互独立 | III-A 中 d 做正弦变化时，s 的跟踪不受影响 | p.7–8 |
| C1 负距离能被动产生接触力，并避免失去接触 | III-B 三种方法对比（Table II）：力的均值和标准差分别为 −2.178/0.521 N（B1）、−2.183/0.495 N（B2）、−2.403/0.498 N（B3）。B1 在 t≈23 s、B2 在 t≈7 s 各失去一次接触，并随后产生冲击；B3 几乎全程接触 | Fig.8, Table II, p.7–8 |
| C3 能在网格上实时运行 | 13367 个顶点、26360 个面；建树 18 ms；t_call=11.91 ms；3 kHz 回路 | p.6 |
| 手把手引导与遥操作 | 只在视频中展示 | p.6 |

- **对照为什么这样选**：
  - B1 代表 RUS 现有做法（预计算轨迹 + 笛卡尔阻抗 + 前馈力）[原文 p.7]；
  - B2 是**内部消融**：几何坐标与本文相同，只把"负距离"换成"前馈力"，从而把收益归因到产生接触力的机制上 [原文 p.7–8]；
  - 最接近的 [7] 和 [16] 没有被复现。
- **刚度设置**：B3 的 k_d=250 N/m，低于 III-A 的 1000 N/m（Table I）。刚度值"基于启发式实验检查和硅胶已知刚度"选取 [原文 p.7]。
- **指标**：选的是任务物理量（距离 d、外力 F_z 的均值和标准差、是否失去接触）。B3 在力的稳定性上**没有优势**（标准差 0.498 N，对照 0.495–0.521 N），平均力也偏离 2 N 更多（2.403 N）；作者的表述是"comparable"[原文 p.8]。真正的优势只是没有发生失去接触和冲击。
- **规模**：每种条件只有一条轨迹、一次运行；只用一个模体，探头是假的（圆柱加球头，长 14 cm）；**没有超声图像，也没有人体实验** [p.6]。
- **核心优势的证据形式**：失去接触和随后的冲击只能从 Fig.8 的时序图看出，正文没有报告冲击峰值、失去接触的时长或次数统计（Codex 提出，已核）。
- **计算时间**：报告了，但有上述 ms 与 3 kHz 的矛盾。

## 7. 贡献定位

- **作者自称**：C1 在任意曲面上做阻抗控制，能连续调节接触力并控制压入深度；C2 一种新的、尊重曲面几何与曲率的任务坐标，可用于三种扫描模式；C3 在三角网格上 3 kHz 实时 [原文 p.2]。
- **实际增量**：一种重新表述：把"沿曲面带力扫描"写成"在曲面导出坐标中做经典阻抗控制"。C1 和 C3 都由 C2 派生：C1 是在这套坐标里设一个负设定值，C3 是现成图形学工具的工程实现。
- **层次**：表述/坐标层面的机制贡献，带来"不用力控制、在任意曲面上被动接触"的能力。[推断] 作者自称与实际增量一致，没有夸大成新的控制理论。RA-L 篇幅有限，作者也没有把 C3 包装成算法贡献。不过，"for Ultrasound Scanning"写进了标题，实验却没有任何超声图像质量证据，应用层面的主张只到"控制行为"为止。

## 8. 关键决策点

**D1 接触力怎样产生**
- 可能的选项：前馈力 / 直接或混合力控制 / energy tank 加力跟踪（[7]）/ 纯阻抗加负设定值
- 实际选择：纯阻抗加负设定值
- 放弃了什么：力的精确跟踪；平均力没有被精确设定（B3 为 2.403 N）
- 理由：[原文 p.1, p.8] 力控制在失去接触时不无源；负距离还能直接限定压入深度
- 对后文的影响：实验的核心对比就落在"失去接触"这一点上，而不是力的精度

**D2 几何放在哪里**
- 可能的选项：预计算笛卡尔轨迹 / 在曲面上定义任务坐标
- 实际选择：任务坐标
- 放弃了什么：用一条 SE(3) 轨迹表示扫描路径
- 理由：[原文 p.2] 预计算轨迹无法支持手把手模式，而任务坐标让三种模式共用一个控制器
- 对后文的影响：雅可比的推导必须用微分几何

**D3 代理点怎样取**
- 可能的选项：带一阶动力学的代理点（[16]）/ 最近点查询
- 实际选择：最近点查询
- 放弃了什么：代理点轨迹的天然连续性
- 理由：[原文 p.5] 坐标只依赖 q 时，任务力才能积分成势场，无源性才能沿用经典结论；连续性靠限制 \|d\|<r_min 保证
- 对后文的影响：适用范围被限制在曲面附近（d_max=15 mm）

**D4 曲面怎样表示**
- 可能的选项：解析曲面（[7][24]）/ 点云 / 三角网格
- 实际选择：三角网格
- 放弃了什么：解析曲面上的精确曲率
- 理由：[原文 p.5] 网格可以从 CAD、三维扫描或视觉获得，还能处理任意拓扑和尖角
- 对后文的影响：需要曲率估计、重心插值和 AABB 树；这部分可以从计算机图形学直接借用

**D5 姿态坐标怎样定义**
- 可能的选项：完整的三维姿态 / 只约束工具轴与法向对齐
- 实际选择：用四元数向量部表示工具轴与法向的相对旋转
- 放弃了什么：绕探头轴的旋转（留作未来工作 [p.8–9]）
- 理由：[推断] 超声扫描首先要求探头垂直于皮肤，绕轴旋转可以交给零空间或第七关节弹簧处理 [p.6]
- 对后文的影响：任务维度从 6 降到 4（或加上 s 后为 6），冗余由零空间处理

**D6 曲面上的位置用不用坐标表示**
- 可能的选项：始终参数化 / 可选参数化
- 实际选择：做成可选项。交互模式只用 p，遥操作和自主扫描时加上 s（ARAP）
- 放弃了什么：要求曲面有全局参数化（这要求曲面是盘状拓扑 [p.6]）
- 理由：[原文 p.4, p.6] 交互时不应约束位置；遥操作需要等距映射
- 对后文的影响：拓扑假设只影响可选部分，不影响核心方法

**D7 要不要写新的稳定性证明**
- 可能的选项：写一个新定理 / 依靠经典结论
- 实际选择：依靠经典结论（"inherently"）
- 放弃了什么：对尖角、离散化和 \|d\| 边界附近行为的形式化保证
- 理由：[推断] 重新表述的价值就在于让成熟保证直接适用；RA-L 篇幅也有限
- 对后文的影响：审稿人可能追问网格离散化后的无源性

**D8 实验怎样设计对照**
- 可能的选项：复现 [7] 或 [16] / 用 RUS 常见做法 / 做内部消融
- 实际选择：常见做法（B1）加内部消融（B2）
- 放弃了什么：与最接近工作的直接对比
- 理由：[推断] B2 可以把"失去接触"的问题归因到前馈力，而不是归因到几何；但这样一来，无法回答"[7] 在网格上是否同样能做到"
- 对后文的影响：主张局限于"不用力控制也能达到相近的力水平，且不失去接触"

**形成过程的依据（成稿之外）**：
- [原文 p.9] 参考文献 [18] 是 Albu-Schäffer 与 Sachtler（本文通讯作者）2022 年的 arXiv 论文，研究构型空间的准正交叶状结构。本文在 p.3 说"与 [18] 的思路类似，先在 S₀ 上定义坐标，再推广到其他叶"。[推断] "叶状结构 / 任务坐标"这一视角来自本组同期的理论工作；本文把它用到 RUS 上，再用计算机图形学工具解决离散实现。外域工具（图形学）负责"能实现"，本组理论负责"怎样表述"。
- DLR 的无源阻抗控制传统（[17][19][32] 都出自本组）为 D1 和 D7 提供了直接依据。[推断] 在这样的组里，"不用力控制、只用无源阻抗"几乎是默认的价值取向，这一点影响了问题本身的定义方式。

## 9. 弱点与处理

审稿人可能从以下几处攻击：
- 题名写的是超声，实验却没有超声图像；
- 每种条件只有一次试验；
- 力的稳定性没有优势；
- 没有复现最接近的 [7] 和 [16]；
- t_call 与 3 kHz 矛盾；
- 网格离散化与尖角处没有无源性分析；
- 硅胶模体不能代表真实组织的变形和滑动；
- 正文只给出接触力的公式 d=f/(k_d−k_O)，没有用实验检验它 [p.3]；
- **对最接近工作的表述前后不一**：p.1 承认 [7] 对任意被动环境证明了无源性和稳定性；p.8 却把 [6][7] 一起归为"在失去接触时固有地存在无源性与稳定性问题"[原文 p.1, p.8]。后一句的概括比前一句宽（Codex 提出，已核）。

**作者的处理**：
- 把临床设置、可变形组织（靠刚度估计更新网格）和绕轴旋转都明确列为未来工作 [p.8–9]；
- 用"comparable"而不是"better"描述力的结果 [p.8]；
- 承认在高曲率区域关节速度会变大，并提出可以通过量化曲率与关节速度的关系来限速 [p.8]。

[推断] 局限写得具体，主张与证据大体相符；最弱的一环是题名与证据之间的距离。
