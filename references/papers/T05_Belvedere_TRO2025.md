# T05 Belvedere 等 T-RO2025：参数不确定下的灵敏度感知 MPC

> 近年顶刊样本。短画像，只记录科研判断。Claude 读原文（2026-10-29），本文原为第二轮留出检验论文，检验后纳入。页码为 PDF 页码。

**基本信息**：T. Belvedere, M. Cognetti, G. Oriolo, P. Robuffo Giordano（CNRS/Inria Rennes、LAAS、罗马大学）；IEEE T-RO 41, 2025，20 页。2024-09 收稿，2025-03 接收 [原文 p.1]。PDF：`D:\桌面\科研Agent Harness设计\impedance-control-e2e\source-materials\` 下的 `Sensitivity-Aware_Model_Predictive_Control_for_Robots_With_Parametric_Uncertainty.pdf`。类型：方法型（鲁棒 MPC），用四旋翼验证。

**一句话逻辑链**：机器人模型的主要不确定性常集中在少数参数上，这种不确定性有结构，利用它能更准确地预测偏差 [原文 p.1–2] → 本组前作用闭环状态灵敏度生成对参数不敏感的轨迹，并得到状态和输入的"管道"，但都只用于离线规划 [原文 p.2] → 已有鲁棒 MPC 处在一条谱系上：简单方法用固定的辅助反馈律，离线性化点远时性能下降；复杂方法保证强，但计算量比普通 MPC 高几个数量级 [原文 p.2–3] → 用优化问题的灵敏度分析在线算出 MPC 自身的等效反馈增益，代替预先固定的辅助控制器，使不确定性预测反映硬约束对反馈的影响，计算量与普通 MPC 相当 [原文 p.3] → 大规模仿真统计加机载实物实验 [原文 p.10–16]。

## 五个阶段的判断

- **现状**：把已有鲁棒 MPC 排成一条"复杂度—鲁棒性"的谱系，写出两端各自的代价，把本文定位在谱系中间 [原文 p.2–3]。对相邻的灵敏度用法（为学习对 MPC 求导、采样间隔内的高频反馈）写明区别：它们只把增益用于即时反馈，本文要在整个预测时域内传播闭环灵敏度 [原文 p.3]。
- **问题**：问题来自本组前作的局限（只能离线）[原文 p.2]，一次只推进一步：把已有的灵敏度管道搬到在线 MPC 中。
- **方法**：瓶颈落在"预测用的反馈律与 MPC 实际施加的反馈不一致"上；从优化理论借来灵敏度分析，算出 MPC 自己的增益 [原文 p.3]。还给出用现成 QP 求解器和标准多重打靶时计算增益的方法，使方法不依赖专用求解器 [原文 p.3]。
- **实验**：
  - 对照：普通 MPC、最接近的鲁棒方法 zoRO，以及把增益换成 LQR 式增益的变体（只为检验"考虑约束的增益"这一机制）[原文 p.12–14]；
  - 解释为什么赢：两种不确定性传播方式不同 [原文 p.14]；
  - 统计仿真之后做机载实物实验，并单独分析计算复杂度 [原文 p.10]。
- **贡献**：首次把闭环灵敏度用于在线的优化型控制器，相对本研究线写明增量；实用价值写成贡献：可以给任何现有 MPC 加一层鲁棒性，计算开销很小 [原文 p.3]。
