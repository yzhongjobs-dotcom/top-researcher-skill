# 参考资料层

逆向分析真实顶会顶刊的产出，用来深化和校正规则层（[workflow/](../workflow/)），让 agent 知道顶刊在每个阶段实际做到什么程度、作者怎样做出决定、普通论文差在哪里。按需加载：阶段文件写明遇到什么情况读哪份参考。只引用一层，不互相嵌套引用。

论文类型只粗分两类，作为适用条件标注，不用来切分文档：

- **理论/方法型**：贡献是通用的新表述、新机制或新保证，应用用于演示。
- **应用/问题驱动型**：贡献是在具体任务中获得某种能力；系统集成类工作通常归入这一类。

所有分析区分 **[原文]**（作者明说，附 PDF 页码、公式或图号）和 **[推断]**（分析者判断）。引用原文只用短句，不复制大段内容。

## 阶段参考模板：`stages/<阶段>.md`

1. **顶刊实际怎么做**：多篇论文在这一阶段的具体做法，附论文与页码。
2. **作者怎样决定**：面对哪些选项、依据什么选择、放弃了什么。
3. **变化范围**：随论文类型、期刊怎样不同；哪些是共性，哪些只是个例。
4. **好与普通的差别**：同一阶段好论文和普通论文的具体对比；普通论文差在哪里，顶刊通常怎样补足（如会议版到期刊版补了什么）。
5. **锚点论文**：按类型列出这一阶段最值得对照的 2–3 篇，以及对照时看什么。
6. **用于自己的工作**：在这一阶段对照锚点时要问的问题，和 agent 常犯的错误。

每条结论都能回查到 `papers/` 或 `comparisons/` 中的实例；推翻或补充规则层时，标明对应 workflow 文件的哪一条。

## 单篇画像模板：`papers/<编号或作者>_<短名>_<期刊年份>.md`

**重点是作者的科研判断**：研究现状按什么逻辑组织、问题为什么这样定、方法怎样从问题里长出来、实验怎样从主张出发、贡献放在哪个层次，以及与普通论文差在哪里。不做写作分析，不做审稿式挑错，不专门核对图表数字；单篇画像是 `stages/` 的原料，控制在约 3000 字。

文件头写明分工与核对方式：Claude 对照 PDF 原页核对并定稿，Codex 的第一遍或挑错意见经核实后并入，标"（Codex 提出，已核）"。页码一律写 PDF 页码。

1. **基本信息**：题名、作者与单位、期刊/会议、年份、收稿与接收日期、年均引用、论文类型、PDF 路径、实际读过的页码范围、所读版本（正式版或预印本）。论文类型按**证据落在哪一层**归类：贡献和证据都在通用方法层的，归入理论/方法型，即使动机来自应用；证据到达任务或系统层（任务成功率、临床或图像指标、系统级用户实验）的，归入应用/问题驱动型。
2. **全文逻辑链**：一段话写清：应用需求 → 核心矛盾 → 已有方法卡在哪里、为什么 → 核心洞见 → 方法 → 证据 → 主张。
3. **研究现状**：已有工作按什么组织；最接近的工作是哪几篇，怎样正面比较；差距怎样确立（是"没人做过"，还是从对手的表述或实验中推出缺陷）。
4. **研究问题**：问题层级；核心矛盾或缺失的能力（两难时，两端怎样排序）；重要性从哪里来；解决后改变什么。
5. **方法**：相对最强已有方法的实际增量；继承了什么、改了什么；怎样从问题中长出来，每个部件对应哪个困难（用表）；是否有更简单的替代；理论与执行是否闭合（逐项说明保证的对象和缺口）；为什么一看就像顶刊方法（问题怎样形式化、符号与假设怎样交代、理论放在哪里、实现细节写到什么程度）。
6. **实验验证**：主张—证据对照表；对照为什么选、怎样保证公平；场景、消融、指标、实物与计算时间。重点看实验怎样从主张推出、对照怎样选（数字只取正文文字中写出的）。
7. **贡献定位**：作者自称的贡献与实际增量是否一致；放在哪个层次（模块、机制、关系、能力、框架）。
8. **关键决策点（5–10 个）**：每个写五行：可能的选项 / 实际选择 / 放弃了什么 / 理由（[原文] 或 [推断]）/ 对后文的影响。
9. **形成过程的依据（成稿之外）**：同组前后论文、投稿与接收日期、互引关系、作者后续工作对本文的评价；只作为 [推断] 的依据。
10. **弱点与处理**：审稿人可能攻击什么；作者怎样写局限和边界；原刊笔误与前后不一致（核实后记录）。
11. **对规则层的作用**：支持、修正或反驳了 workflow 中的哪一条，适用条件是什么（用表）。

文末附"待核对清单"。

## 两两对比模板：`comparisons/<A>_vs_<B>.md`

0. 两篇的简要画像（各用单篇模板第 1、2、5、6、7 项压缩写）；已有单篇画像的，直接链接。
1. 为什么比较这两篇：同一研究线前后版本、顶刊与非顶刊，还是同刊不同形态；同一研究线的，列出时间线与互引关系。
2. 共同点。
3. 各阶段的差异：研究现状、研究问题、方法、实验验证、贡献定位，附页码与原页数字。
4. 差异说明了什么：多了什么才到顶刊，作者升级时补了什么、删了什么、仍缺什么。
5. 关键决策点（升级或分化时的选择）。
6. 对 `stages/` 的结论（用表），标明适用条件和可能的反例。
