# 阶段参考层：怎样用它判断和优化一个 idea 或一个 section

本文件夹是从真实顶会顶刊逆向分析得到的**判断工具**。它回答两个问题：

1. 一个 idea（或论文的某个 section）是否达到顶会顶刊的标准？
2. 如果没达到，差在哪里，怎样改到顶刊水平？

五个阶段文件与规则层 [workflow/](../../workflow/) 一一对应：

| 文件 | 判断对象 |
|---|---|
| [01_literature.md](01_literature.md) | 研究现状：最强方法做到哪里、缺口在哪里 |
| [02_problem.md](02_problem.md) | 研究问题：值不值得做、定得准不准 |
| [03_method.md](03_method.md) | 方法：是否从问题里长出来、是否专业完整；方法怎样找到 |
| [04_experiments.md](04_experiments.md) | 实验：证据能否支撑主张 |
| [05_contribution.md](05_contribution.md) | 贡献定位：放在哪个层次、相对谁、强度是否与证据一致 |

每个阶段文件的结构相同：**要回答的问题 → 底线 → 加分 → 适用条件 → 诊断表 → 升级样板 → 锚点论文**。另有几节专用内容：02 的"taste 检验"（问题值不值得做），03 的"怎样找到方法"，04 的"证据配置一览"（证据够不够），02、05 的"通用改写"。

自测记录见 [evals/2026-10-29_stages_self_check.md](../../evals/2026-10-29_stages_self_check.md)。

- **底线**：样本中几乎所有已发表的顶会顶刊都满足的做法。不满足底线，基本不像顶会顶刊。每条底线都注明样本中的例外，以免把"常见"误当成"必要"。
- **加分**：多数一档期刊（T-RO、IJRR）样本具备、会议和短文常省略的做法。目标档次越高，需要的加分越多。
- **档次**（细节，不必过多关注）：T-RO、IJRR 为第一档；TMECH、TCYB 等为第二档；RA-L、ICRA 为第三档。会议和短文篇幅短，常只做一个聚焦的增量。**已发表的论文都是正例**：判断时不能拿一档期刊的加分项去否定已被会议接收的工作。

## 一、判断流程

1. **定类型**：理论/方法型（贡献是通用的表示、机制或保证），还是应用/问题驱动型（贡献是在具体任务中获得某种能力）。同一项工作只按一种类型判断，避免"四不像"。
2. **逐阶段查底线**：对相关阶段的每条底线回答"满足 / 部分满足 / 不满足"，并写出依据（原文的哪句话或哪个实验）。
3. **查跨阶段闭环**（见下一节）：这是顶刊最核心的特征，必须单独检查。
4. **按目标档次查加分**：目标越高，需要的加分越多。
5. **用诊断表给出改法**：每个"不满足"对应诊断表里的一行，写出具体改法和对照的锚点。
6. **参考升级样板**：找最相近的真实"前版 → 后版"，看作者实际补了什么。

**输出格式**

```
类型：理论/方法型 | 应用/问题驱动型        目标档次：……
结论：已达到 [档次] 的底线 / 未达到，差在 [哪几条底线]
| 阶段 | 底线条目 | 判断 | 依据 | 改法（对照锚点） |
跨阶段闭环：通 / 断在 [哪一环]
若要提升到 [更高档次]，优先补：1. …… 2. ……
```

## 二、跨阶段闭环（所有顶会顶刊样本都满足的核心特征）

顶刊论文的四个阶段指向同一件事：

> **问题**里写出的机制原因 = **方法**改动的位置 = **实验**检验的主张 = **贡献**陈述的能力

| 例子 | 问题中的机制原因 | 方法改动的位置 | 实验检验的主张 | 贡献陈述的能力 |
|---|---|---|---|---|
| R13 | 能量函数的形状同时决定精度和收敛 | 能量函数的表示与参数约束 | 同一训练目标下只换表示，比较一致性；再比较整体复现误差 | 稳定且精确的示教学习 |
| L02 | 不稳定交互中，只学力会失效 | 力、刚度、阻尼同步学习 | 三种扰动分别检验三个部件；只学前馈的对照失败 | 处理不稳定交互的类人适应 |
| L10 | 可操控性与接触稳定性此消彼长 | 人的力决定参考，学习补偿环境扰动 | 同时测路径误差和人的施力 | 同时保证二者 |
| T04 | 精度与柔顺在反馈控制中冲突 | 精确的前馈模型承担精度 | 增益降两个数量级后的跟踪精度 | 同时柔顺且精确 |

**检查方法**：用一句话分别写出四格。只要有一格写不出，或者两格说的不是同一件事（例如问题说的是"环境未知"，实验测的却是"计算速度"），闭环就断了。闭环断开时，先修闭环，再修各阶段的细节。

**普通论文最常见的断点**：问题写"前人没考虑 X"（没有机制原因），方法是"模块 A + 模块 B"（改动位置与问题无关），实验与"固定参数"比较总误差（不能归因到机制），贡献写"提出了一个框架"（没有能力）。
