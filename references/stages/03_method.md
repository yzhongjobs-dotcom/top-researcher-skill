## 要回答的问题

怎样让方法从问题里长出来，并准确解决问题？怎样做到专业完整？怎样快速验证、怎样迭代？

## 一、怎么做（顶刊研究者的做法）

> 成稿不反映真实的发现顺序。以下做法依据成稿中"问题 → 方法"的对应关系，以及研究线的前后版本归纳而来，属于 [推断]。

### A. 从问题到方法：六步

1. **把问题里的机制原因（阶段二的产出）落到一个对象上。** 问：瓶颈在表示、模型、信息、求解还是执行？
   - 表示：R13 的能量函数、T03 的策略表示；
   - 模型：T04 的逆动力学、JinT 的阻抗模型输入形式；
   - 坐标或接口：Dyck 的任务坐标、C01 的 DS 执行方式。
2. **问：要让所需性质成立，这个对象应当满足什么条件？**
   - R13：能量沿每条射线单调递增，就能保证唯一极小，而这比凸性弱得多 [R13 p.6–7]；
   - Dyck：坐标只依赖关节构型，任务力就能积分成势场，从而无源 [Dyck p.5]；
   - C01：只在与任务无关的方向耗散能量，就能既无源又跟随任务 [C01 p.1–2]。
3. **找"已经在别处满足这个条件"的东西，做一次重新表述，让它可以直接用。** 阶段一记下的外域工具清单在这里使用。来源有两类：
   - **人或生物的做法**：L01、L02 把人的适应规律拆成三项，分别对应补偿力、增加阻抗、减少能耗 [L01 p.3]；L07 借用"参考轨迹随接触面变形" [L07 p.2]；
   - **其他领域的成熟工具**：C03 的内模控制（化工过程控制）[C03 p.1]；C02 的 PI2（随机最优控制）[C02 p.2]；T03 的张量列（数值数学）[T03 p.3]；Dyck 的离散微分几何（图形学）；T01 的扩散模型；L04 的 ADP；L05 的博弈论。

   重新表述的标准写法是："把 X 视为 Y，问题就变成 Z，于是可以直接利用 Z 的 [性质]"：
   - L04：把交互力视为环境系统的输入，最优阻抗就成为 LQR，再用 ADP 在环境未知时求解 [L04 p.6–7]；
   - C02：把增益调度和参考轨迹放进同一个 DMP，PI2 就能同时优化二者 [C02 p.2–3]；
   - T03：把策略写成优势函数的 arg max，就能用参数分布加权 [T03 p.2]；
   - Pol：把冲击扰动视为某个初值下的自由响应，鲁棒约束就有闭式上界 [Pol p.5–7]；
   - JinT：把阻抗参数直接当作输入，变阻抗律设计就成为控制律设计 [JinT p.4]。

   判断一次重新表述好不好，就看它换来了什么：现成的保证、闭式解，还是可在线求解。
4. **只改瓶颈，其余继承，并写明继承了什么。** R13 只改能量函数，修正用的 QP 和原始动力系统的回归都沿用 [R13 p.5–11]；L07 只加轨迹自适应 [L07 p.2–3]；Dyck 只改任务坐标 [Dyck p.3–6]。
5. **从目标推出方法，让想要的行为自然产生。** 先写目标（代价或期望性质），由目标推出更新律或结构，再证明它满足目标：
   - L02 从"不稳定性 + 运动误差 + 努力"推出学习律并证明收敛 [L02 p.1, p.3, p.7–8]；
   - C02 只在代价中惩罚高增益，"能柔则柔、必要时变硬"就自然出现 [C02 p.2–3]；
   - L08 选择更新律，使 Lyapunov 导数中的交叉项抵消，于是辨识对方和调整自己可以同时进行 [L08 p.6]。
6. **检查能否把已有方法纳入为特例。** 能的话，增量最清楚：R13 中 WSAQF 和 ICNN 是特例 [R13 p.7]；L05 中已有方法 [10] 是某个权重下的特例 [L05 p.3]；T03 中域随机化和域自适应是特例 [T03 p.8]；L08 只改代价权重，就覆盖了协作、竞争、辅助等多种行为 [L08 p.6–7]。

### B. 需要多个机制时：先找冲突，再按冲突分工

每个部件只负责一种困难或两难的一端，并写清它们怎样配合。近年常见的分工是：学习负责难以建模的部分，经典控制结构负责保证。

- L10：人的力通过导纳决定参考运动（负责可操控性），学习补偿环境扰动（负责接触稳定性）；学习方式按任务是否重复来选 [L10 p.3–6]；
- T02：深度强化学习做前馈（非线性），变阻抗做反馈（稳定与收敛）[T02 p.3–5]；
- T01：扩散模型从接触中推断平衡，阻抗控制保证能量一致 [T01 p.2]；
- C03：内模控制注入期望阻抗并纠正误差，时延估计抵消动力学 [C03 p.1]；
- Wij：高层轨迹优化规划运动与力，底层导纳力控处理模型误差 [Wij p.2]。

### C. 保证怎样做：先问能否由构造保证

1. **能由结构直接保证的，就由构造保证**：R13 用参数约束保证唯一极小，任何训练结果都满足 [R13 p.6]；Dyck 用只依赖构型的坐标，使无源性成为结构自带的性质 [Dyck p.5]。
2. **做不到时，用成熟的事后机制，并写清代价**：Jin TMECH2023 用 energy tank 事后修正；tank 耗尽时刚度会切换、产生颤动 [JinT p.9]。同一作者后来在 TMECH2025 中改为由构造保证稳定（见 R13 画像第 8 节）。
3. **每个保证都写清对象、条件、没保证的部分**：C01 写明系统无源，但不一定渐近稳定 [C01 p.2–3]；L08 写明在持续激励下收敛 [L08 p.6]；L07 写明没有证明学到的参数收敛到真值 [L07 p.4]；Pol 写明稳定与性能冲突时只保证稳定 [Pol p.10]。

### D. 快速验证与迭代

1. **先分析，再实验**：C03 在相同估计误差的假设下比较各方法的传递函数，说明本方法为什么误差更小 [C03 p.4–5]；R13 先用二维例子展示表示的局限 [R13 p.4]。
2. **最小原型保留的是机制，不是完整系统**：L01 只用 1 自由度，就能区分"调力"与"调阻抗"两种行为 [L01 p.1, p.6]。
3. **让上一版的具体失效决定下一次改动**：
   - L02 在障碍处力过大 → L07 加入轨迹自适应 [L07 p.1]；
   - Wij 会议版是两块分解 → 期刊版拆出逆运动学成为三块，并改为在线 MPC [Wij p.2–3]。
4. **为保持整体一致，可以删掉旧机制**：JinI 用额外的补偿力处理状态约束；JinT 删掉它，改由阻抗参数统一实现约束，才能统一做无源性分析 [JinI p.3–4；JinT p.5–7]。
5. **原型收益不足时，先查是哪一环没起作用**（估计、决策还是执行），只改那一环；如果最强基线本身已经足够好，回到问题阶段重新审视。这与规则层第 7 步一致。

### 这一阶段的产出

1. 一句话写清："继承了 X，改了 Y，因此新增了能力 Z"；
2. 一张"部件 → 困难"对应表，以及部件之间怎样配合；
3. 问题最看重的性质怎样保证：对象、条件、没保证的部分；
4. 一个保留了关键机制的最小原型，以及它的初步结果；
5. 下一轮要改的那一环。

## 二、做到什么程度（尺子）

### 底线（几乎所有顶会顶刊样本都满足）

| 编号 | 判据 | 样本情况 |
|---|---|---|
| B1 | 每个关键部件都对应问题中的一个困难 | 全部正例：R13 p.5–7；L02 p.3–4；C03 p.1；Beb（组织模型 → 期望力与压入上限；tank 加功率约束 → 限制能量注入）p.2–4 |
| B2 | 写明继承了什么、改了什么（A 的第 4 步） | 几乎全部正例：R13、L07、Dyck、T04、Beb p.3–4。对照样本 FuT 与 [19] 结构相同，却没写继承关系 [FuT p.2–3] |
| B3 | 方法完整可执行：输入输出、模型与假设、求解或训练方式、执行接口；不显然的假设写出来 | 全部正例。L04 写明假设内环是理想的、环境参数为常数 [L04 p.4–5]；L05 写明假设人不会故意制造失稳 [L05 p.5] |
| B4 | 问题最看重的性质有定理、推导、结构保证或机理依据 | 全部正例，形式不同：定理（R13、L02、L05、L08、JinT、Pol、T02、T03）；结构自带（Dyck）；机理分析（C03）；物理依据（A02：入射角接近零时回波最多 [A02 p.2]） |

## 三、适用条件

- **理论/方法型**（R13、Pol、C01、C03、T03）：核心是一个新的表示、结构或条件，配有定理。
- **方法型，学习与控制结合**（T01、T02、T04、C02）：常见"学习负责难建模的部分，经典结构负责保证"，理论多落在经典结构一侧。
- **应用/问题驱动型**（L10、A 序列、Beb）：方法是按流程或按困难分工的组合；每个关键部件要有物理或信号上的依据；信息接口常需专门设计（L10 用一个机构把人的力与工具接触力分开测量 [L10 p.10]）。
- **控制理论或学习控制期刊**（L03、L04、L09）：常是"学一个最优参数 + 处理系统不确定性"两个模块，配完整的稳定性证明。
- **档次**：会议和短文常只有一个关键改动、满足底线即可；一档期刊多数具备 P1–P3。

## 四、自检与改进（诊断表）

| 症状 | 没达到哪条 | 怎样改 | 对照 |
|---|---|---|---|
| 方法是"模块 A + 模块 B"，说不清每个模块解决哪个困难 | B1、P5 | 做 B：先找冲突，再按冲突分工 | L10 p.3–6；C03 p.1 |
| 用了成熟模板，没写来源和改动 | B2 | 写"继承了 X，改了 Y，新增能力 Z" | Beb p.3–4 |
| 关键假设没写，或执行接口没交代 | B3 | 列出假设及其适用条件；写清输入输出与执行方式 | L04 p.4–5 |
| "加了某机制所以安全或稳定"，没有依据 | B4、P3 | 做 C：能否由构造保证？写清对象、条件、没保证的部分 | R13 p.6；C01 p.2–3 |
| 外域方法直接套用，没有改写问题 | P1 | 做 A 的第 3 步：改写成什么形式，工具才能直接用；换来了什么 | L04 p.6–7；T03 p.2 |
| 想要的行为靠额外规则或手调 | P2 | 改写代价或结构，让行为自然产生 | C02 p.2–3 |
| 方法像"又一个变体" | P4 | 检查已有方法能否成为特例 | R13 p.7；T03 p.8 |
| 直接上完整系统，效果不好时不知道哪里错 | P6、D | 先分析；用保留机制的最小原型 | L01；C03 p.4–5 |
| 实现与方案名称不符，或用数值结果冒充理论保证 | B3、B4（规则层"AI 犯过的错"） | 区分理论对象与数值实现；名称只描述实际做的事 | Pol p.10 |
| 想不出方法 | — | 回到 A 的第 1–3 步：对象 → 条件 → 在别处找满足条件的东西 | — |

## 五、升级样板（真实的前版 → 后版）

| 前版 | 后版 | 方法这一步改了什么 |
|---|---|---|
| L01：1 自由度迭代版，更新律按行为原则设计，没有证明 [L01 p.3] | L02：从代价推出连续时间学习律，证明收敛，推广到多自由度 [L02 p.3, p.7–8] | 从"按原则设计"到"从目标推出并证明" |

| Wij 会议版：两块分解，离线 [Wij p.2] | Wij 期刊版：三块分解，在线 MPC，加底层力控 [Wij p.2–3] | 分工更细，执行闭环 |
| Jin RA-L2022：选择 Lyapunov 函数的准则（附属一节）（见 R13 画像第 8 节） | R13：可学习、由构造保证唯一极小的能量函数成为主贡献 | 前作中的一个子问题提升为核心表示（[推断]） |

## 六、锚点论文

| 类型 | 锚点 | 对照时看什么 |
|---|---|---|
| 单处改动，由构造保证 | R13 | 怎样设计表示，使要保证的性质变成参数约束（p.5–7） |
| 从目标推出方法 | L02 | 代价 → 学习律 → 收敛证明；每一项对应一种行为 |
| 重新表述 | L04、T03 | 改写成什么形式，成熟工具才能直接用 |
| 学习与控制分工 | T01、T02 | 学习负责什么，控制结构负责什么，怎样衔接 |
| 应用型组合 | L10 | 按冲突的两端分工；学习方式随任务结构选择 |
| 会议短文 | Dyck、Beb | 一个关键改动怎样写得完整 |
