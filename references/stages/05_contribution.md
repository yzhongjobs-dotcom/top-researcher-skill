# 阶段五参考：顶刊怎样定位贡献

> 对应规则层 [workflow/05_writing.md](../../workflow/05_writing.md) 中属于科研判断的部分：贡献放在哪个层次、相对谁、强度是否与证据一致。不涉及写作技巧。本文件写顶会顶刊的**共性做法（即标准）**，再写随论文类型、期刊变化的**适用条件**。例证编号见 [01_literature.md](01_literature.md) 开头的表格；页码为各论文 PDF 页码。

## 一、顶刊共性（标准）

### 1. 贡献放在能力层，而且每个层次都有对应的证据

**通用表述**：贡献写成"带来了什么能力或认识"，而不是"用了什么模块"。如果贡献同时放在几个层次（机器人能力、理论保证、科学理解），每个层次都要有对应的证据。

**例证**：
- L05：机器人能根据人的意图连续调整角色（能力），并在双智能体协调博弈意义下最优（理论）[L05 p.1]。
- L10：在人—机器人—环境交互中同时保证可操控性和接触稳定性 [L10 p.1]。
- L02：既是能处理不稳定交互的控制器（机器人能力，有机器人实验），也是能预测已发表人类观察的运动适应模型（科学理解，有人类实验的复现）[L02 p.10–11]。
- T01：定位在框架层，即连接信息域与能量域；讨论中的结论写得具体："装配成败取决于名义参考与生成阻抗的相互作用"[T01 p.12]。

**通用改写**：
- 普通写法："本文提出了一个包含模块 A、B 的框架。"
- 顶刊形态："本文使 [系统] 在 [条件] 下获得了 [能力]；其关键在于 [机制]；理论上保证了 [性质]（在 [条件] 下）。"

### 2. 改动小，按它带来的能力写：先老实写做了什么，再写它带来什么

**通用表述**：小改动不需要夸大，也不需要回避。先如实写出做了什么（包括"这是一个组合"），再写这个改动带来的新能力。

**例证**：L06 的第一条贡献写"结合 EMG 与 DMP"，再用"more importantly"写刚度与运动可以同时泛化 [L06 p.1]；L07 只加入轨迹自适应，但把它写成接触加工与触觉辨识中的通用交互能力 [L07 p.1, p.9]。

### 3. 增量相对谁要写准：最接近的工作、本组前作，继承与改动都写明

**通用表述**：每条贡献都隐含"相对于谁是新的"。顶刊会写明这个参照：相对最接近的工作新在哪里，相对自己的前作新在哪里；理论增量写到"首次分析了某种耦合"这种精确程度。

**例证**：L07"首次分析阻抗/力适应与轨迹适应之间的耦合"[L07 p.2]；Pol 写明相对会议版的主要贡献是去掉"惯量对角"的限制 [Pol p.2]；Wij 列出相对会议版的三处扩展 [Wij p.2–3]；T03 写明建立在作者前作之上，扩展为完整的仿真到实物框架 [T03 p.3]；Beber 写明受 [29] 启发，主要区别有两处 [Beber p.3–4]。

### 4. 主张强度与证据一致：理论主张带条件，局限写到"根本问题还没回答"

**通用表述**：每条主张的强度不超过证据：理论结论带上成立条件；比较结论按条件写；局限写具体，最好写到"哪个根本问题还没有回答"，而不只是"以后做更多实验"。

**例证**：
- 理论带条件：L08 写明辨识在持续激励下收敛 [L08 p.6]；C01 写明无源但不一定渐近稳定 [C01 p.2–3]。
- 局限写到根本问题：L05 写明不知道 Nash 均衡在哪里、是否存在 [L05 p.9]；L07 写明没有证明学到的参数收敛到真值 [L07 p.4]；C01 写明无源对安全只是必要条件，不是充分条件 [C01 p.6–7]。
- 克制的措辞：L07 写明"我们并不声称达到人的操作智能"[L07 p.9]。
- 主动回答最可能的根本质疑：L08 讨论"这是否要求人的控制真的符合博弈论"，答案是结论不依赖这一假设 [L08 p.11–12]。

### 5. 实用价值也可以是贡献

**通用表述**：方法简单、需要调的参数少、不需要昂贵传感器、可以实时运行、能凭直觉调参，这些都可以写成贡献，前提是有对应的证据或分析。

**例证**：C03 把"控制律简单、尽量少用动力学模型"列为要求和贡献 [C03 p.1–2]；C02 写明除了探索噪声不需要调任何参数 [C02 p.1]；C01 建立与经典阻抗的联系，使阻抗可以凭经验直观调节 [C01 p.2, p.5]；Pol 和 L02 写明不需要力传感器 [Pol p.4；L02 p.4]。

### 6. 能统一已有方法的，定位为框架；完成某个研究纲领的，写明是哪一个

**通用表述**：如果本文把已有方法纳入为特例，或者用一个框架覆盖多种行为，贡献就可以放在框架层；如果完成了领域里某个已提出的研究纲领，要写明是哪一个。

**例证**：T03 证明域随机化和域自适应都是本文框架的特例 [T03 p.8]；L08 写明本文完成了文献 [13] 提出的纲领 [L08 p.12]；R13 把 WSAQF 和 ICNN 纳入为特例 [R13 p.7]。

## 二、作者怎样决定

| 决策 | 常见选项 | 顶刊样本的选择与理由 |
|---|---|---|
| 放在哪个层次 | 模块 / 机制 / 能力 / 框架 | 按证据能支撑的最高层次放，通常是能力层（共性 1） |
| 小改动怎样写 | 夸大成新范式 / 只列模块 / 先如实写再写能力 | 先如实写，再写带来的能力（共性 2） |
| 相对谁 | 不写 / 写最接近的工作与前作 | 写明，并写到精确的增量（共性 3） |
| 局限怎样写 | 不写 / 笼统写 / 写到未解的根本问题 | 写到未解的根本问题（共性 4） |

## 三、适用条件（随类型与期刊的变化）

- **理论/方法型**：贡献常落在"新的表示、条件或框架"加上"由此带来的保证"（R13、T03、C01）。
- **应用/问题驱动型**：贡献常落在"首次自动完成某个流程环节"或"在某类交互中获得某项能力"，并写明相对最接近系统的区别（A01 相对 [19]：用可变形配准和通用图谱，使没有断层图像的患者也能扫描 [A01 p.1–2]）。
- **面向广泛读者的期刊**（L08）：贡献写在领域层面（"首个能理解人类控制策略并作出最优反应的交互控制器"），理论细节放在 Methods。
- **控制理论或学习控制期刊**（L03、L04、L09）：贡献常按模块列出（环境模型、学习律、内环控制器），层次停在机制；这与机器人顶刊的能力层写法不同，作为条件记录。
- **短文**（RA-L、ICRA）：贡献通常 2–3 条，集中在一个关键改动上（Dyck、C01）。

## 四、与普通论文的差别（辅助）

普通论文常见两种偏差：一是把小组合夸大为"新框架"，或者把来自别的部件的收益归到核心方法上（例如 Fu T-RO2025 中工作负荷的下降主要来自共享控制，摘要却归于整个变阻抗框架 [Fu T-RO p.1, p.17]）；二是贡献按模块罗列，看不出带来了什么能力。顶刊的做法见共性 1–4。

## 五、锚点论文（定位贡献时对照）

| 类型 | 锚点 | 对照时看什么 |
|---|---|---|
| 能力层，多层证据 | L02 Yang T-RO2011 | 机器人能力与科学理解两层，各有证据 |
| 小改动的定位 | L06 Yang TMECH2018 | 先如实写组合，再写能力 |
| 精确的增量与局限 | L07 Li T-RO2018 | "首次分析某种耦合"；写明没证明什么 |
| 框架层 | T03 Xue IJRR、L08 Li NMI2019 | 已有方法作为特例，或完成已提出的纲领 |

## 六、用于自己的工作

**定位贡献时逐条自问：**
1. 每条贡献带来了什么能力或认识？对应的证据是哪一个实验或定理？
2. 如果改动小，我有没有先如实写做了什么，再写它带来的能力？
3. 每条贡献相对谁是新的？最接近的工作和我自己的前作都写明了吗？
4. 理论主张的条件写了吗？比较结论是否按条件写？局限有没有写到"哪个根本问题还没回答"？
5. 有没有可以写成贡献的实用价值（简单、少调参、少传感器、实时）？证据在哪里？
6. 能不能把已有方法纳入为特例？

**agent 容易犯的错**（对应规则层的"AI 犯过的错"）：
- 夸大：例如写"首次联合估计 X 与 Y""近最优"，证据并不支持。
- 过度保守：因为部件是成熟的，就低估实际贡献；正文堆满限定语。
- 把方法写成模块清单，看不出每个模块带来了什么能力。
