# 阶段一：研究现状

> 对应规则层 [workflow/01_literature.md](../../workflow/01_literature.md)。用法和例证编号见 [README.md](README.md)。页码为各论文 PDF 页码。

## 要回答的问题

最强的已有方法做到了哪里？在什么条件下停下，为什么停下？缺口在哪里，是否真实、是否重要？

---

## 一、怎么做（顶刊研究者的做法）

### 1. 从最接近的一两篇强工作出发，读到方法和实验

不要先从综述铺开、广撒网。先锁定与问题最近的一两篇强工作，读懂它的机制、能力和边界，再沿引用链前后追，把直接相关的工作找全。同期的工作和作者自己的前作都要找到。

- C03 从文献 [10] 报告的两难出发，把三种已有实现逐一读到机制层 [C03 p.1]。
- R13 锁定三个已经保证唯一极小的能量函数（WSAQF、FDM、ICNN），分别读清它们的局限 [R13 p.2–3]。
- T01 找到了同期最接近的工作 ACP，并逐项比较 [T01 p.2]。
- Pol、Wij、T03 都从自己的前作出发，写明前作做到了哪里 [Pol p.2；Wij p.2–3；T03 p.3]。

### 2. 对每条路线问四句：做到什么、依赖什么、在哪失效、为什么

每读完一条路线，写下这四句。读者应当能从这四句里自己推出缺口。

- L04 按"依赖什么"层层排除：被动阻抗过于保守 → 启发式变阻抗难以推广 → 迭代学习需要重复 → LQR 需要已知环境 [L04 p.2–3]。
- C03 写出三种实现的失效机制：对模型误差敏感；内环动力学被激发；除非内环与期望阻抗一致，否则不准 [C03 p.1]。
- T02 写出三类方法的失效条件后，用一段总结把三者并列 [T02 p.1–2]。

### 3. 问：这些不足是不是同一个原因？

如果能找到一个维度，同时解释多条路线的不足，缺口就会自然显现，后面的问题和方法也就有了方向。

- T01：所有路线的不足都落在"信息域与能量域之间没有接上"[T01 p.1–2]。
- R13：两种主流范式都受能量函数形状的制约 [R13 p.4]。
- T03：域随机化与域自适应之间是"泛化与最优"的两难 [T03 p.2]。
- C01：DS 的问题都来自开环执行 [C01 p.1]。

### 4. 对最强的工作，先承认它做到了什么，再找它做不到的

不回避强 prior，也不笼统批评它。先写出它已经做到的部分（包括它能保证什么），再写它的哪个结构使它在什么条件下做不到。剩下的部分，就是不会被它直接否定的缺口。

- R13 先承认三个能量函数都保证唯一极小，再指出它们的灵活性分别卡在类二次型、拓扑约束、凸性上 [R13 p.2–3]。
- Wij 先说接触感知的轨迹优化效果出色，再指出优化出的接触力没有用于控制 [Wij p.2]。
- T03 先承认显式自适应在四足行走上表现出色，再指出它需要精确辨识，而接触任务中难以做到 [T03 p.2]。

### 5. 判断缺口属于哪种形态

顶刊的缺口通常属于以下之一。写不出属于哪种，说明还要继续追问（回到第 2 步），或者这个缺口不重要。

| 形态 | 例子 |
|---|---|
| 已有方法的前提在目标场景中不成立 | L05（已有角色调整需要离散切换或共同目标）[L05 p.1–2]；Pol（需要惯量整形）；Beb（假设组织均匀）[Beb p.2] |
| 两类文献的交叉处 | L10（人机交互不考虑环境，机器人—环境交互不考虑人）[L10 p.2] |
| 前作的具体失效或未解问题 | L07（前作在障碍处力过大）[L07 p.1]；L08（L05 留下的均衡问题） |
| （应用型）流程中某个环节还不能自动完成 | A01、A02、A03 |
| "没人做过 X"，但能说明 X 关系到什么 | JinI（阻抗约束决定最差情况的柔顺度）[JinI p.1]；L01 [L01 p.1] |

最后一种在会议论文中可以接受；期刊论文通常要进一步写到前三种。

### 6. 外域工具单独记下，留给方法阶段

调研中发现的其他领域的工具（过程控制、随机最优控制、数值方法、图形学、生成模型）不写进现状，单独记下它的哪个性质可能对应本问题的难点，留到方法阶段使用（C03 的内模控制 [C03 p.1]；C02 的 PI2 [C02 p.2]）。

### 这一阶段的产出

1. 一张表：路线 | 做到什么 | 依赖什么 | 在哪失效 | 为什么；
2. 最接近的一两篇工作，以及本工作与它们的具体区别；
3. 统一的维度（如果有）；
4. 缺口一句话，并注明属于哪种形态；
5. 外域工具清单（留给方法阶段）。

## 二、做到什么程度（尺子）

### 底线（几乎所有顶会顶刊样本都满足）

| 编号 | 判据 | 样本情况 |
|---|---|---|
| B1 | 找到最接近的工作，并写出本工作与它的具体区别 | 全部正例，包括会议短文：JinI 点名最相关的 [20] [JinI p.1]；Beb 写明相对 [29] 的两处区别 [Beb p.3–4]；A03 指出 A01 的轨迹来自术前 MRI，物体一动就失效 [A03 p.1–2]。对照样本 FuT 与 [19] 结构相同，却只写对方"未考虑变形和闭环力控" [FuT p.2] |
| B2 | 缺口具体，并写出不解决会怎样 | 全部正例。最低限度是"没人做 X，而 X 关系到 Y"（JinI、L01） |
| B3 | 现状围绕研究问题，按路线或能力分组，而不是罗列 | 全部正例。分组方式可以不同：按工具（L03）、按流程环节（A01）、按技术路线（T02） |

### 加分（多数一档期刊样本具备）

| 编号 | 做法 | 样本 |
|---|---|---|
| P1 | 每条路线写到前提或失效机制 | C03、JinT p.3、Pol、T03、R13、T02、L05。L10 没有写到机制，仍被一档期刊接收，因为它的问题新（两类交互的交叉处） |
| P2 | 用一个统一的视角组织多条路线 | T01、R13、T03、C01 |
| P3 | 对概念最相近的方法，专门写机制区别 | C03（单列一节并做实验）p.2；T01 p.2；C01 p.1；Dyck（与动态代理点的区别）p.5 |
| P4 | 同期工作和本组前作都写到，并写明增量 | Pol、Wij、T03、L07。JinT、FuR 没写自己的前作也被接收，所以这不是底线，但缺了它增量的可信度会下降 |

## 三、适用条件

- **理论/方法型**：按表示、假设、解的结构分组；缺口常是"某个表示或假设限制了能力"。
- **应用/问题驱动型**：按"系统已能完成流程中的哪一步"分组；缺口常是某个环节还不能自动完成，或两类交互没有同时考虑。
- **档次**：会议和短文常只满足底线，并把现状并入引言；一档期刊多数具备 P1，常具备 P2–P4。

## 四、自检与改进（诊断表）

| 症状 | 没达到哪条 | 怎样改 | 对照 |
|---|---|---|---|
| 写"已有方法未考虑 X"，没说不考虑会怎样 | B2 | 补一句后果：哪种任务会失败、失败成什么样 | JinI p.1 |
| 最接近的工作没出现，或被笼统归入"一类方法" | B1 | 回到第 1 步，点名一两篇，写出区别 | R13 p.2–3；Beb p.3–4 |
| 文献逐篇罗列，看不出分组 | B3 | 按第 2 步的四句分组 | T02 p.1–2 |
| 对强方法的批评是"效果不好""不够通用" | P1；稻草人风险 | 写出它的前提和失效条件 | C03 p.1；JinT p.3 |
| 各路线的不足彼此无关 | P2 | 做第 3 步：找同一个原因 | T01 p.1–2 |
| 看到强 prior 就想换题或缩题 | 规则层"过度防守" | 做第 4 步：承认后找剩余 | Wij p.2；T03 p.2 |
| 外域方法被写成本领域的竞争者 | 第 6 步 | 移出现状，留给方法阶段 | C03 p.1 |

## 五、升级样板（真实的前版 → 后版）

| 前版 | 后版 | 现状这一步改了什么 |

## 六、锚点论文

| 类型 | 锚点 | 对照时看什么 |
|---|---|---|
| 理论/方法型 | C03 | 每个已有方法的失效机制；与最相似方法的专门比较 |
| 理论/方法型 | T03 | 多条路线怎样排进一个两难；承认最强方法后找剩余 |
| 方法型，跨范式 | T01 | 一个概念框架怎样组织几条看似无关的路线 |
| 应用/问题驱动型 | L10、A 序列 | 缺口落在两类交互的交叉处，或流程中的某个环节 |
| 会议短文 | JinI、Beb | 底线怎样在很短的篇幅里满足 |
