# 检验：agent 是否真的达到了顶刊研究者水平

做法参照 skill 评测：让一个**只读过本文件夹**的全新 agent（subagent 或 Codex）完成留出任务，与原文或用户判断对比；差在哪里，就补哪里的规则或参考资料。

| 任务 | 做法 | 对比对象 |
|---|---|---|
| 预测作者决策 | 只给留出论文的摘要和问题，预测其方法设计、对照选择、贡献定位 | 原文 |
| 评审与重写引言 | 评审一篇留出论文的引言并重写 | 原文与用户评判 |
| 应用于真实项目 | 重写一个在研项目的研究问题、贡献和实验设计 | 用户评判 |

留出论文清单见 [PLAN.md](../PLAN.md)，检验前不读、也不交给 Codex。每次检验的输入、输出和结论记在本目录，以日期命名。
